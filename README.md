# Calculator

An iPhone-style calculator built in SwiftUI.

## Features

- Add, subtract, multiply and divide, with chained operations
- Percent, plus/minus and decimal input
- Backspace (⌫) and clear (AC)
- The familiar layout: dark keypad and orange operator keys

## Run it

1. Open `CalculatorApp.xcodeproj` in Xcode.
2. Choose an iPhone simulator.
3. Press **Run** (⌘R).
